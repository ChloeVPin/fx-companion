# Code of Conduct

fx-companion is a technical open source project. Contributions and discussions should stay focused, constructive, and useful to the people doing the work.

## Expected behavior

- Treat contributors and users with respect.
- Critique code, measurements, and technical claims rather than people.
- Provide reproducible evidence when disputing correctness or performance claims.
- Respect privacy. Do not post another person's private information, credentials, logs containing secrets, or private repository contents.
- Accept maintainer decisions about scope, safety, and release readiness without harassment.

## Unacceptable behavior

Harassment, threats, discriminatory attacks, deliberate disruption, impersonation, doxxing, spam, and repeated bad-faith behavior are not welcome.

## Enforcement

Maintainers may edit or remove content, close or lock discussions, reject contributions, or restrict participation when behavior interferes with a safe and productive project environment.

For security-sensitive reports, follow `SECURITY.md` rather than posting details publicly.
