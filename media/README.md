# Launch media

These files are intentionally minimal and monochrome.

- `fxc.svg`: the three-letter `fxc` mark, converted to vector outlines from
  Vercel Geist Sans SemiBold. No font file is embedded or distributed.
- `demo.cast`: real asciinema capture of the pinned production discovery
  benchmark on the 51,200-file fixture.
- `demo.gif`: rendered directly from `demo.cast` with Geist Mono.
- `benchmark.png`: static benchmark card using the recorded clean-room Apple M2
  production results.
- `social-preview.png`: 1280 x 640 GitHub/social preview asset.

The benchmark source data is tracked in
[`../benchmarks/results/latest.json`](../benchmarks/results/latest.json) and the
measurement methodology is documented in
[`../benchmarks/results/2026-09-07-launch-readiness.md`](../benchmarks/results/2026-09-07-launch-readiness.md).
